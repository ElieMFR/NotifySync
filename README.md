Same plugin, same features as the Jellyfin 10.11 build — a separate branch only because one binary cannot target both versions at once.

*Même plugin, mêmes fonctionnalités que la version Jellyfin 10.11 — une branche séparée uniquement parce qu'un même binaire ne peut pas viser les deux à la fois.*

## Repository / Dépôt

Add this in **Dashboard → Plugins → Repositories**, then install **NotifySync (Jellyfin 12)** from the catalog.

*À ajouter dans **Tableau de bord → Extensions → Dépôts**, puis installez **NotifySync (Jellyfin 12)** depuis le catalogue.*

```
https://raw.githubusercontent.com/peterdu1109/NotifySync/refs/heads/jellyfin-12/repository-12.json
```
